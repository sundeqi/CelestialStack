# 月亮堆栈 · 用户使用说明书

0.3.1 公开测试版 | Apple Silicon · macOS 15+ | 2026-10-06

## 第一次使用

月亮堆栈将同一拍摄组的 RAW 照片合成为一张图像，并提供曝光、明暗对比、AI 降噪和锐化调节。照片在本机处理，原始 RAW 不会被覆盖。

1. 打开安装包，将“月亮堆栈.app”拖入“应用程序”。
2. 从应用程序文件夹启动，选择 RAW 所在文件夹。
3. 扫描照片，查看数量和读取问题，点击“下一步”。
4. 填写拍摄间隔，选择输出目录，保留默认处理设置。
5. 点击“检查任务”，确认后点击“开始堆栈”。
6. 完成后点击“打开双窗编辑与导出”，观察并调整右图。
7. 选择 TIFF、JPG 或同时导出，查看保存成功提示和文件路径。

## 中英文切换

在欢迎页或界面右上角选择“简体中文 / English”。默认中文，选择会自动保存。切换不会重启任务或重置图像调整；其他窗口会同步语言。原始诊断日志保留原文，系统文件选择器的部分文字跟随 macOS 语言。

## 系统与格式

| 项目 | 要求或说明 |
|---|---|
| 电脑 | Apple Silicon（M 系列）Mac，macOS 15 及以上 |
| 照片 | 至少 10 张同一拍摄组的可读取 RAW |
| 输入格式 | Sony ARW、Nikon NEF、Panasonic RW2、Canon CR2 / CR3 / CRW |
| 输出格式 | 16 位 TIFF、最高质量 JPG |

目前主要完成 Sony ARW 实拍验证。其他品牌的具体机型与压缩模式仍需样本验证。此安装包不适用于 Intel Mac、Windows 或视频素材。

建议先用 10-20 张照片熟悉操作。处理整组照片时，为输出目录预留足够空间；除成片外，程序还会保存任务数据。

# 01 安装与准备照片

## 安装与首次启动

打开 `MoonStack-0.3.1-public-beta-macOS15-arm64.dmg`，将应用拖入“Applications / 应用程序”，随后可推出磁盘映像。不要拆开应用包移动内部文件。

本测试版尚未完成 Apple Developer ID 签名和公证。首次启动若提示无法验证开发者，请先确认下载来源并核对发布页 SHA256 校验值。在确认可信后，可按 Apple 官方指引查看“系统设置 > 隐私与安全性”中的“仍要打开”选项。

若系统提示恶意软件或文件损坏，应先停止打开并反馈。不要关闭系统整体安全保护。参考：[Apple：在 Mac 上安全地打开 App](https://support.apple.com/zh-cn/102445)。

读取“下载”“文稿”或外接盘时，系统可能询问文件夹权限；仅为你准备使用的目录授予访问权限。

## 整理照片

将同一相机、同一拍摄组、相近焦距和曝光的 RAW 放入一个文件夹。月亮应完整入画。不要混入不同夜晚、不同画幅或明显改变焦距的照片。

程序扫描所选文件夹的当前层，不递归读取子文件夹。JPG、XMP 和隐藏旁车文件不会作为 RAW 输入。文件夹内混有不同拍摄组时，应先自行分开。

扫描失败时，根据“文件清单与读取问题”查找异常照片；将其移到另一个文件夹，再重新扫描。修改扩展名不会使不支持的格式变得可读。

## 保留原片

TIFF 和 JPG 是处理后的图像，不能代替相机 RAW。请独立保留原片及重要成片。应用产生的任务文件较多，不要在处理过程中手动删除。

# 02 新建堆栈任务

## 选择并扫描

点击“选择文件夹…”打开系统目录选择器，或使用“手动填写路径”。查看数量、机型（可识别时）、尺寸和读取问题。可按 RAW 格式筛选输入。

少于 10 张、存在不可读照片或发现多组不一致素材时，“下一步”可能不可用。扫描通过后仍可能在完整处理时遇到不兼容或不适合堆栈的照片。

扫描后不要增删或修改输入文件；如有变化，请重新扫描。

## 拍摄间隔与输出位置

间隔按“本次曝光开始到下一次曝光开始”的秒数填写，未知可以留空。若相机设置表示曝光结束后再等 1 秒，且曝光为 1/250 秒，则可填 1.004；若设置本身表示曝光起始间隔，则填 1。以相机对该选项的定义为准。

选择已有且可写入的输出父目录。程序会为本次任务新建文件夹；完成后的“任务信息”区域会显示实际位置。

## 处理设置

初次使用建议保留默认堆栈模式和 25% 选帧比例。界面允许调整目标比例；更高比例不保证更清晰。实际使用数量还受照片质量和处理通过情况影响。

额外 AI 降噪、锐化、明暗对比及曝光调整初始均为 0。建议完成堆栈后，再在双窗中逐项调整。

## 开始与停止

点击“检查任务”确认路径及设置，再点击“开始堆栈”。下方日志显示进展。进入编辑器前可能仍需等待预览准备完成。

“停止任务”会终止计算，可能保留部分任务文件；目前不能从中断位置续算。关闭主窗口或 Cmd+Q 也会结束当前处理。重跑会创建新的任务目录。

# 03 双窗查看与调整

## 查看同一片月面

左图为程序自动选取的最佳单张，右图为堆栈结果。两侧同步缩放和拖动；可选择适合窗口、100%、200% 或 400%，也可点击“月面居中”。

左图不随右侧调节变化。建议在 100% 下观察相同的环形山、月海与月缘。不同软件的锐化刻度没有统一标准，不能直接按相同数字比较效果。

| 调节项 | 使用方法 |
|---|---|
| 整体曝光 | -3 至 +3 EV；亮区刺眼时可先尝试降低 0.3 EV |
| 明暗对比 | 0-100%；也可选弱、较弱、中、较强、强五档 |
| AI 降噪 | 0-100%，0 关闭；纹理变平时应降低强度 |
| 自然锐化 | 0-100%，0 关闭；出现亮边、暗边或颗粒时应降低强度 |
| 六层小波 | 可展开精细调整；由细到粗调节不同大小的细节，初次使用建议保留默认值 |

## 建议操作顺序

1. 全部归零，先观察未经额外调整的右图。
2. 调整曝光，再逐渐增加明暗对比，检查亮区是否仍有层次。
3. 逐渐增加锐化；如噪声明显，再适量增加降噪并重新检查细纹理。
4. 停止拖动，等待“右图已更新”，确认效果后导出。

“曝光归零”和“明暗对比归零”分别重置对应项。“全部归零”重置主要增强强度；若调整过小波各层，可另用“恢复默认层配方”。

已经在拍摄时过曝丢失的纹理无法通过降低曝光恢复。堆栈和增强也不能保证恢复失焦、抖动或大气扰动造成的全部细节。

# 04 导出、重新打开与反馈

## TIFF 还是 JPG

| 格式 | 建议用途 |
|---|---|
| 16 位 TIFF | 无损保存当前成片，适合归档和继续后期；文件较大 |
| 最高质量 JPG | 适合浏览、分享和发布；仍为 8 位有损格式 |

拿不准时，选择“同时导出 TIFF + 最高质量 JPG”。两种格式均保存右图当前效果。点击导出并看到成功提示后，文件已写入本地；“下载”链接用于另存一份。

14 bit RAW 与 16 位 TIFF 表示不同处理阶段的数据精度，不能仅按位数判断画质。16 位 TIFF 有利于后期和减少保存时的量化损失，但不会凭空增加原片细节。

## 找到文件与重新编辑

在“任务信息”中查看输入路径、照片清单、参考照片及实际导出路径。建议保留完整任务文件夹；仅保留 TIFF/JPG 可以查看成片，但无法恢复完整编辑流程。

启动应用后可选择“打开已有堆栈结果…”，选取任务目录或其中的 `result` 目录。当前版本移动或重命名任务目录后可能无法重新打开；建议保留原位置。重新打开时主要调节值回到零，不会自动恢复上次会话。

## 常见问题

| 现象 | 建议 |
|---|---|
| 下一步不可用 | 检查数量、读取问题及是否混入不同拍摄组，再扫描 |
| 白色区域太亮 | 降低曝光或对比，检查原片是否已经过曝 |
| 月缘光晕或纹理粗糙 | 降低锐化，在 100% 倍率下重新观察 |
| 导出失败 | 检查输出目录权限和剩余空间，保留简短错误信息 |

删除应用不会自动删除照片与任务结果。反馈请使用 GitHub Issues，注明应用、系统和相机信息，提供复现步骤；截图及日志请先遮挡用户名、完整路径等私人信息。
