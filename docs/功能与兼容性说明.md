# 星体堆栈 · 功能与兼容性说明

0.3.5 公开测试版 | 2026-10-07

## 产品用途

星体堆栈面向同一拍摄组的月亮 RAW 照片，提供从目录选择、素材检查、堆栈到成片调整与导出的本地工作流程。无需另行安装运行环境。

## 功能范围

| 功能 | 说明 |
|---|---|
| 天体类型 | 目前仅支持月亮；欢迎页和任务设置可查看此选项 |
| 界面语言 | 简体中文 / English，即时切换并记住选择 |
| 素材检查 | 选择 RAW 文件夹，查看格式、数量、文件清单及读取问题 |
| 任务设置 | 记录拍摄间隔，选择输出目录、堆栈模式和选帧比例 |
| 自动处理 | 自动选取参考照片，对齐与合成月亮图像 |
| 双窗查看 | 左侧参考单张、右侧堆栈，同步缩放与拖动 |
| 图像调整 | 曝光、五档或连续明暗对比、AI 降噪、自然锐化及小波精细调节 |
| 保存 | 导出 16 位 TIFF、最高质量 JPG，支持双格式同时输出 |
| 任务信息 | 查看输入、输出位置、参考照片及处理进展 |

照片在本机处理，不需要上传照片完成堆栈。原始 RAW 不会被覆盖。公开提交反馈前，请自行检查照片、截图和错误信息中的隐私内容。

## 适用设备

本安装包面向 Apple Silicon（M 系列）Mac，最低系统要求为 macOS 15，目前实机验证系统为 macOS 15.8.1。尚未提供 Intel Mac 或 Windows 安装包。

应用尚未完成 Apple Developer ID 签名及公证；首次打开可能受系统安全检查限制，处理方法见用户手册及 Apple 官方说明。

# 兼容性与测试版限制

## 相机格式

提供 Sony ARW、Nikon NEF、Panasonic RW2、Canon CR2 / CR3 / CRW, Fujifilm RAF 的读取入口。当前实拍验证主要来自 Sony ARW；其他格式的具体机型及压缩模式仍需进一步验证。

扩展名相同不代表内部编码一致。扫描成功也不保证所有照片都能完成后续处理；发现不支持或损坏的文件时，应按提示更换素材。请勿混用不同相机、焦距或拍摄组。

## 画质预期

堆栈旨在利用多张照片改善成片质量，实际收益取决于原片对焦、曝光、抖动、大气条件、可用照片数量和内容一致性。不承诺任何一组素材都能达到更高真实分辨率，亦不承诺与其他商业软件画质等效。

锐化能使细节更醒目，也可能放大噪点和光晕；降噪过强可能使细纹理变平。请结合 100% 查看与最终展示尺寸判断效果。

## 当前限制

- 原始诊断日志保留原文；系统文件选择器的部分文字跟随 macOS 语言。

- 至少需要 10 张可读取、属于同一拍摄组的 RAW；不支持视频输入。
- 只扫描选定文件夹的当前层，不自动收集子目录素材。
- 处理中断后不能原地续算，重新处理会建立新任务。
- 移动或重命名已完成的任务目录后，重新打开可能失败。
- 重新打开已有结果时，不自动恢复上次会话的增强参数。
- 处理耗时与空间占用随照片尺寸、数量和电脑性能变化，尚无统一最低内存或耗时承诺。

## 版本与反馈

本次为公开测试分发，提供安装包、使用说明和问题反馈入口，暂不公开应用源码。公开测试不构成未来版本免费或持续维护的承诺。

请在仓库 Issues 中提交机型、系统、相机、格式、数量、复现步骤和简短错误提示；不必公开原始照片或整个任务文件夹。第三方组件版权与许可证声明随安装包提供。

## 富士 RAF（0.3.4）

支持自动发现和单独筛选 RAF，通过 LibRaw 解码 X-Trans 或 Bayer 传感器数据。公开 X-T2 未压缩/无损压缩及 X-A1 未压缩样本已通过传感器解包和 16 位 RGB 解码。其他具体机型与压缩模式需实样验证；尚未验收富士月亮连拍组的完整堆栈效果。

## 构图留白

0.3.4 在 0.3.3 的月亮边缘留白基础上再增加 25%，裁切尺寸按处理需要向上取整。通过读取更多原片背景实现，不缩小月亮或添加人工黑边。已有结果保持不变，需要重新堆栈获得新的留白。
